## Version note

This harness pins **MuJoCo 3.2.6**. The upstream `doc/skills` directory does
not exist at that tag — these guides first appear in MuJoCo 3.14.0. They are
included as reference material and may describe APIs added after 3.2.6. Check
the guide against the pinned `mujoco==3.2.6` API before relying on a specific
call.
