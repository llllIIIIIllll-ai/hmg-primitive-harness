## Version note

This harness pins **MuJoCo 3.2.6**. The guides track upstream `main`, so they
may mention APIs added after 3.2.6. Treat them as reference material and check
a call against the pinned API before relying on it.

See `PORTING.md` for which guides apply to this harness and which are not used.
