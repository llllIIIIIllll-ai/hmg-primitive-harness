# Pinned skill sources

This directory contains only the `.py` files that the skill catalogue pins:
each `library/skills/<name>.md` names its source path relative to this
directory. They are the exact sources used for the verified runs.

Not included: actor probes, queues, traces, episode outputs, videos, verifier
scratch directories, and the rest of the task working tree. Those are runtime
artefacts and are intentionally excluded from the repository.
